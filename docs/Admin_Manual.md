## Getting Started

### Signing Up (Public Registration)
1. Navigate to the registration page
2. Enter your email address
3. Create a password with:
   - Minimum 8 characters
   - At least one uppercase letter
   - At least one lowercase letter
   - At least one number
4. Click "Register" to create your account
5. You will be registered as a regular USER

### Logging In
1. Navigate to the admin panel login page
2. Enter your admin credentials (email and password)
3. Click "Login" to access the dashboard
4. You will receive a JWT token for API authentication

### Authentication
All admin actions require authentication. Include the JWT token in the Authorization header:
```
Authorization: Bearer <your_jwt_token>
```

## User Management

### Creating a New User
1. Navigate to the Users section in the admin panel
2. Click "Add New User"
3. Fill in the required fields:
   - **Email**: Valid email address (required)
   - **First Name**: User's first name (optional)
   - **Last Name**: User's last name (optional)
   - **Phone**: Phone number (optional)
   - **Password**: Minimum 6 characters (optional)
   - **Role**: Select from USER or ADMIN (defaults to USER)
   - **Status**: Select ACTIVE, INACTIVE, or SUSPENDED (defaults to ACTIVE)
4. Click "Save" to create the user

### Editing a User
1. Go to the Users list
2. Find the user you want to edit
3. Click the "Edit" button
4. Modify the fields as needed
5. Click "Save" to update

### Deleting a User
1. Go to the Users list
2. Find the user to delete
3. Click the "Delete" button
4. Confirm the deletion
5. **Note**: You cannot delete your own admin account

### User Status Management
- **ACTIVE**: User can log in and use the system
- **INACTIVE**: User cannot log in
- **SUSPENDED**: User account is suspended (cannot log in)

## Book Management

### Creating a New Book
1. Navigate to the Books section
2. Click "Add New Book"
3. Fill in the book details:
   - **Title**: Book title (required)
   - **Slug**: URL-friendly identifier (required, unique)
   - **Short Description**: Brief summary (optional)
   - **Description**: Full description (optional)
   - **ISBN**: International Standard Book Number (optional)
   - **Price**: Regular price (required)
   - **Discount Price**: Sale price (optional)
   - **Publication Date**: Release date (optional)
   - **Edition**: Edition information (optional)
   - **Language**: Book language (optional)
   - **Stock**: Available quantity (optional, defaults to 0)
   - **Status**: DRAFT, PUBLISHED, or ARCHIVED (defaults to DRAFT)
   - **Publication**: Link to publication (optional)
   - **Subject**: Link to subject (optional)
4. Click "Save" to create the book

### Book Status Flow
- **DRAFT**: Book is being prepared, not visible to customers
- **PUBLISHED**: Book is live and available for purchase
- **ARCHIVED**: Book is no longer available for purchase

### Adding Book Parts
1. Open a book for editing
2. Go to the "Parts" tab
3. Click "Add Part"
4. Enter:
   - **Title**: Part title (required)
   - **Part Number**: Order sequence (required)
   - **Description**: Part description (optional)
   - **Price**: Part price (optional)
5. Click "Save"

### Adding Book Attachments
1. Open a book for editing
2. Go to the "Attachments" tab
3. Click "Add Attachment"
4. Select attachment type:
   - **THUMBNAIL**: Book cover image (also stored in the main `thumbnail` field)
   - **IMAGE**: Additional book images
   - **PDF**: Digital book file
   - **BANNER**: Promotional banner
5. Upload the file (files are stored on Cloudinary)
6. Set display order
7. Click "Save"

**Note:** The `publicId` is automatically generated by Cloudinary and stored for future deletion. When you delete an attachment, the file is also removed from Cloudinary.

### Adding Reviews/Testimonials
1. Open a book for editing
2. Go to the "Reviews" tab
3. Click "Add Review"
4. Enter:
   - **Reviewer Name**: Name of reviewer (required)
   - **Designation**: Reviewer's title (optional)
   - **Rating**: 1-5 stars (required)
   - **Comment**: Review text (optional)
   - **Display Order**: Sort order (optional)
5. Click "Save"

## Category Management

### Creating a Category
1. Navigate to Categories section
2. Click "Add New Category"
3. Enter:
   - **Name**: Category name (required)
   - **Slug**: URL-friendly identifier (required, unique)
   - **Parent ID**: For sub-categories (optional)
4. Click "Save"

### Hierarchical Categories
- Categories can have parent-child relationships
- Example: "Books" > "Fiction" > "Mystery"
- Use Parent ID to create nested categories

### Managing Categories
- Edit category details
- Delete categories (soft delete)
- Reorganize by changing parent ID

## Teacher Management

### Creating a Teacher
1. Navigate to Teachers section
2. Click "Add New Teacher"
3. Enter:
   - **Name**: Teacher's full name (required)
   - **Designation**: Title/position (optional)
   - **Bio**: Biography (optional)
   - **Photo**: Profile image URL (optional)
   - **Social Links**: Facebook, LinkedIn, Website (optional)
   - **Display Order**: Sort order (optional)
   - **Featured**: Mark as featured teacher (optional)
4. Click "Save"

### Associating Books with Teachers
1. Open a teacher's profile
2. Go to "Books" tab
3. Click "Add Book"
4. Select a book from the list
5. Click "Save"

- Remove book associations using "Remove" button
- Teachers can be associated with multiple books

## Order Management

### Viewing Orders
1. Navigate to Orders section
2. View list of all orders
3. Each order shows:
   - Order number
   - Customer
   - Total amount
   - Status
   - Date

### Order Status Updates
1. Open an order
2. View order details:
   - Items purchased
   - Shipping address
   - Payment status
3. Update status:
   - **PENDING**: New order, awaiting processing
   - **CONFIRMED**: Order confirmed, being prepared
   - **PROCESSING**: Order is being processed
   - **SHIPPED**: Order has been shipped
   - **DELIVERED**: Order delivered to customer
   - **CANCELLED**: Order cancelled
   - **RETURNED**: Order returned by customer

### Order Notes
- Add notes for internal tracking
- Notes are not visible to customers

## System Settings

### Managing Settings
1. Navigate to Settings section
2. View all system settings
3. Edit any setting:
   - **Key**: Setting identifier (cannot be changed)
   - **Value**: Setting value
4. Click "Save"

### Common Settings
- **site_name**: Website name
- **currency**: Default currency (e.g., BDT)
- **tax_rate**: Tax percentage

### Adding New Settings
1. Click "Add Setting"
2. Enter key and value
3. Click "Save"

## Audit Logs

### Viewing Activity
1. Navigate to Audit Logs section
2. View all system activities
3. Filter by entity type (Book, User, Order, etc.)
4. Each log shows:
   - Action performed
   - User who performed it
   - Timestamp
   - Old and new values

### Audit Trail
- All create, update, delete operations are logged
- Useful for tracking changes and troubleshooting
- Access restricted to admins only

## Best Practices

### Book Management
1. Always set books to DRAFT first, then PUBLISHED when ready
2. Use meaningful slugs for SEO-friendly URLs
3. Add high-quality images and descriptions
4. Set correct pricing and stock levels
5. Associate books with relevant categories and subjects

### User Management
1. Verify user emails before setting to ACTIVE
2. Use SUSPENDED for problematic accounts
3. Keep admin accounts secure

### Content Management
1. Regularly update banners for promotions
2. Keep teacher profiles current
3. Monitor reviews and testimonials

### Order Management
1. Update order status promptly
2. Add notes for important information
3. Handle cancellations and returns appropriately

### Security
1. Never share admin credentials
2. Log out after sessions
3. Regularly review audit logs
4. Use strong passwords
